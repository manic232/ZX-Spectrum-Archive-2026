About The Archive

In January 2003 I stopped working on this project. I’d grown bored of the tedious process of building the CRASH Smash section — sourcing instructions for each game, creating a page for it, tidying the text and repeating that cycle endlessly. I stopped at Popeye, and for the next 23 years… that’s where it stayed.

Fast-forward to April 2026, and I made the decision to finish what I’d started all those years ago. My initial goal was simply to complete the CRASH Smash section and leave it at that. However, as I started working, I got so many different ideas about how to update and fine-tune things. The HTML was a hideous mess, I used FrontPage 2000 back in 2001 on a Windows 98 or possibly XP machine and was targeting a 1024×768 screen resolution with Internet Explorer 5/6. The world has moved on, and thankfully, so did this project. FrontPage should have been a criminal offence to use, punishable by a fine or short custodial sentence. The code it generates is horrendous, font tags everywhere, random line breaks, just embarrassing.

For this reason, I decided to rebuild the site from the ground up using a modern HTML template/CSS based approach. Every page has been updated using nothing but Notepad++ and a bit of CSS knowledge. I will be honest here, I did use AI at the start to assist. I have never touched CSS before so I did need a little coaching here and there to help me get started.

The site is still intentionally old school, a kind of Web 1.5 if you will!. What do I mean by “Web 1.5”? The site has been rebuilt with modern HTML and CSS, and at a glance it looks fairly up-to-date — but it still runs on frames. One day I’d like to remove them entirely, because they’re not really part of the modern web, but my skill set isn’t quite there yet. Modern browsers will tolerate them, they just aren’t considered good practice anymore. So “Web 1.5” is my way of saying the site sits somewhere between old-school Web 1.0 and the cleaner, frame-free world of Web 2.0.

In 2001, the main purpose of this web site was to accompany a folder I’d built full of Spectrum ROMs, box art, and other bits, all neatly organised into directories that matched the games listed here. Those lists originally pointed to the instructions for each game, but the folder itself is long gone now. So for this 2026 reboot, I decided the best approach was to integrate the box art, instructions, and even the game ROM itself directly into each of the game pages, rather than relying on external folders.

Because of this, I chose to point the game lists to magazine reviews — mainly from CRASH Online — rather than to the instructions. Each game page now has its own dedicated game instructions anyway, so having them link to the instructions made no sense.

It would have been great to have all this functionality back in 2001 when I started the project, but I simply didn’t have the time or patience to carry out all the laborious work. The only reason I’ve managed it now is largely thanks to AI. Copilot has been an essential tool throughout this reboot — helping me generate PowerShell scripts to automate huge chunks of repetitive work, and tackle tasks that would have been too time consuming — not to mention soul-destroying — to do manually.

Much of the material was written by me, with additional information originally sourced from places like World of Spectrum, Rebelstar, and the long-since obsolete WOS CD-ROM. For the 2026 reboot, I used CRASH Online as the primary source for the game reviews. Some games were released too early to have been reviewed in CRASH, and CRASH Online mainly covers the more popular games or those that received a CRASH Smash, so for any reviews I couldn’t source from there, I created them myself using the OCR’d CRASH PDF issues available from the RetroPDF website. Additionally, I used other magazines, such as Your Sinclair and Sinclair User.

A big milestone for me was finally getting the site online through GitHub Pages. It wasn’t something I ever planned — not back in 2001, and not even when I started the 2026 update — but it ended up being the logical next step.

Site Content

Within these pages you’ll find artwork, reviews, instructions, history, interviews, web links, and even the ability to play the games themselves. The site is divided into several sections, all accessible from the main menu at the top of the page.

ZX Spectrum Archive Home - The main landing page. It includes information on the various ZX Spectrum models, and a lot more.

CRASH Smashes - A complete list of all games awarded a CRASH Smash by everyone’s favourite Speccy mag, with links to their reviews.

Ultimate Play the Game - An area focusing on the Spectrum titles created by Ultimate Play the Game.

The Toy Box - A collection of the games I remember playing as a child — the ones that shaped my early Speccy years.

About - This page.

Help - General help and guidance for navigating and using this site.
