Tiki Taca

Created by:Eduardo Martin Torices, Igor Errazkin
Price:Free
Year:2019
Source:zxart.ee

'TIKI TACA' is a 2019 action maze game developed for the ZX Spectrum 48K. The player must find three pieces of a key to unlock a mansion door and escape before running out of energy.

Players navigate isometric mazes, wisely using objects and rationing meals. Not all enemies can be destroyed by shooting, adding a strategic layer to the gameplay.
